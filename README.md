# ВОЛЬТГРАД-88 ⚡

Город, который не гаснет. Пока.

Ретро-футуристический киберпанк-портал в эстетике 1980-х: неон, CRT-сканлайны,
VHS-зерно, синтез звука прямо в браузере. Чистый статический сайт —
HTML + CSS + vanilla JS, без сборки и зависимостей.

## Запуск

Любой статический сервер:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# → http://localhost:8080
```

## Что внутри (13 разделов)

| Раздел | Фичи |
|---|---|
| ⌂ Главная | hero с анимированной сеткой и солнцем, live-телеметрия, лента, ASCII |
| 📼 Лор | таймлайн 1971–1989, 3 секретных документа с дешифровкой вживую |
| ⬢ Корпорации | 6 картелов с метриками угрозы |
| ▦ Районы | SVG-карта города, 6 районов, «камеры» |
| ☰ Эфир | новостная лента с поиском и фильтрами по тегам |
| 🛒 Рынок | чёрный рынок: кредиты, корзина, инвентарь, сохранение в localStorage |
| ⌁ Терминал | интерактивный CLI: `help`, `ls`, `cat`, `hack`, `scan`, `matrix`, `secret`… |
| ♫ Радио | 4 синтвейв-передачи, генерируемые Web-Audio в реальном времени, VU-метр |
| 🪪 Досье | создание персонажа: позывной, класс, параметры |
| ☗ Розыск | доска розыска с наградами |
| ✎ Глоссарий | словарь городского жаргона с поиском |
| 🔐 Секреты | кодекс из 7 следов, финал «Белый сигнал» |
| ⚙ Система | техпаспорт и дисклеймер |

## Скрытое

- **Konami-код** (`↑ ↑ ↓ ↓ ← → ← → B A`) — работает в обеих раскладках,
  разблокирует товар-ключ в магазине.
- Собрать все 7 секретов → финальная сцена «Белый сигнал» и последний документ.
- CRT-режим (кнопка ▦ в шапке), матричный дождь из терминала.

## Структура

```
index.html        — разметка всех 13 разделов
css/style.css     — неоновая тема, CRT, глитчи, адаптив
js/data.js        — весь лор: таймлайн, корпорации, районы, новости, рынок…
js/sfx.js         — звуки интерфейса (Web-Audio)
js/radio.js       — 4-дорожечный секвенсор радио 88.8
js/terminal.js    — CLI-терминал
js/app.js         — состояние, вкладки, магазин, досье, секреты, матрица
assets/img/       — 8 сгенерированных изображений
```
